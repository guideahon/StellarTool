[size=5]Stellar Tool — Table mod merger for Stellar Blade[/size]

[b]Two mods edit the same table, the game loads only one, and you silently lose half of what you installed.[/b] Stellar Tool reads the DataTables inside your mods, shows every change, lets you resolve conflicts, and builds one verified merged container.

[b]Two ways to use it[/b]

[list]
[*][b]Simple[/b] — drop in your mods, click [i]Merge everything[/i], and let the tool resolve conflicts by order (the first mod wins).
[*][b]Advanced[/b] — use the full workbench with mod priority, per-change checkboxes, side-by-side conflict resolution, manual value editing, bulk numeric edits, and savable projects.
[/list]

[b]It shows you exactly what each mod does[/b]

[code]EffectTable · Item_HP_RPotion · CalculationValue: 60 → 30 (-50%)
SkillTable · M_DroidTurret_Laser · AttackDamageRate: 1.5 → 4.5 (+200%)[/code]

Every value can be compared against a vanilla baseline. Conflicts are detected at value level — same table, row, and property with different values — and can be resolved side by side, individually or with [i]prefer this mod for everything[/i]. Identical changes are collapsed automatically.

Non-table assets such as meshes and textures are handled as whole-file replacements with the same check and conflict logic.

[b]Reads Zen/IoStore mods[/b]

Most Stellar Blade mods use Zen/IoStore containers ([code].ucas/.utoc[/code]). Stellar Tool reads them with CUE4Parse. Point it at your Stellar Blade folder once from Settings; Steam is detected automatically. Legacy [code].pak[/code], [code].zip[/code], and loose [code].uasset[/code] folders are supported too.

When merging Zen mods, numeric changes such as HP, damage, shields, and multipliers are written back and round-trip verified. Non-numeric changes such as text, enums, arrays, and object references are shown in the diff but currently skipped during writing because they do not reliably round-trip into a Zen container yet. The tool reports exactly how many changes were applied and skipped.

[b]Main features[/b]

[list]
[*]Load any number of legacy [code].pak[/code] files, [code].zip[/code] archives, loose [code].uasset[/code] folders, or Zen/IoStore mods ([code].ucas/.utoc[/code]).
[*]See real vanilla → modded values with percentages, per row and property.
[*]Select individual changes or toggle complete tables.
[*]Edit final numeric values by hand or apply bulk operations ([code]xN[/code], [code]+[/code], [code]-[/code], clamp, set...) filtered by row-name regex.
[*]Detect and resolve value-level conflicts side by side.
[*]Handle non-table assets as whole-file replacements.
[*]Export selected changes as readable TOML patches, or import a literal TOML patch back as changes.
[*]Output the game's native Zen/IoStore container: [b]zzz_StellarTool_Merged_P[/b].
[*]Round-trip verify every written table after packing; failures are reported instead of silently producing a corrupt merge.
[*]Generate an optional installable [code].zip[/code] ([code]Paks[/code] plus readme) for Vortex or any mod manager.
[*]Include [b]merge_report.txt[/b] with applied changes, skipped changes, and conflict resolutions.
[*]Save mod lists, selections, and resolutions as [code].stproj[/code] projects.
[*]Build a vanilla baseline from your own game copy in one click.
[*]Use the headless CLI for scripts and automation.
[*]Your source mods are never modified; only the chosen output folder is written.
[/list]

[b]Install[/b]

[list=1]
[*]Download and extract Stellar Tool anywhere. It is self-contained and has no installer.
[*]Run [code]StellarTool.exe[/code] and confirm your Stellar Blade folder in Settings.
[*]Drop in your mods, press [b]Analyze[/b], review the changes and conflicts, then merge.
[*]Copy the generated files to [code]StellarBlade\SB\Content\Paks\~mods[/code], or install the generated [code].zip[/code] with your mod manager.
[*][b]Disable or remove the source mods you merged[/b] so they do not override the merged pak.
[/list]

A vanilla baseline is optional but recommended. It lets you see vanilla → modded values instead of only raw mod values.

[b]Requirements and conflicts[/b]

[list]
[*]Windows 10/11. The tool never modifies game files.
[*]The merged pak conflicts by definition with the source mods used to create it. Disable those source mods.
[*]Open source under the MIT license: [url=https://github.com/guideahon/StellarTool]github.com/guideahon/StellarTool[/url].
[/list]

[b]What's bundled[/b]

The download includes [code]StellarTool.exe[/code] and the open-source community CLI tools it drives, unmodified: [b]repak[/b] and [b]retoc[/b] (trumank), [b]UAssetGUI/UAssetAPI[/b] (atenfyr), and [b]cue4parse[/b] (CUE4Parse CLI). Everything is auditable from the repository.
