Stellar Tool is a mod merger for Stellar Blade, built to solve the classic problem: two mods edit the same table file (SkillTable, CharacterTable, EffectTable...), the game only loads one of them, and you silently lose half of what you installed.

Instead of merging blind, Stellar Tool decodes the DataTables inside each mod and shows you every single change as a readable line:

EffectTable · Item_HP_RPotion · CalculationValue: 60 -> 30 (-50%)
SkillTable · M_DroidTurret_Laser · AttackDamageRate: 1.5 -> 4.5 (+200%)

You check the changes you want, and when two mods touch the same value with different numbers, the tool flags it as a conflict and lets you pick the winner side by side. Then it rebuilds the tables and packs everything into a single verified container.

MAIN FEATURES
- Load any number of mods: legacy .pak, zips, loose .uasset folders, and Zen/IoStore mods (the usual Nexus format, .ucas/.utoc) via CUE4Parse.
- Per-change checkboxes: every modified row/property is one line you can keep or drop. Whole tables toggle at once.
- Real before/after values against a vanilla baseline, with percentages.
- Conflict detection at value level, resolved side by side or "prefer this mod for everything".
- Edit the final value by hand, or bulk-edit many numeric values at once (xN, +, -, clamp...) filtered by a row-name regex.
- Export selected changes as readable TOML patches, or import a .toml patch back as changes.
- Duplicate changes across mods are auto-collapsed.
- Output is the game's native Zen/IoStore container, verified after packing, plus an optional installable .zip and a merge_report.txt.
- Two modes: Simple (drop mods, one click) and Advanced (full merge-mod workbench). 10 languages.
- Your source mods are never modified.

BUILD MOD (make your own Stellar Souls mod)
Beyond merging, a "Build mod" tab compiles a custom Stellar Souls mod + CNS helper from a short questionnaire - the exact pak you want, byte-for-byte matching the released files, with an install guide in your language.
- Combat / Outfit / Combat+Outfit, Full or First Run.
- Mini-bosses + NG+ gear drops: all regions or Great Desert, adjustable density, progressive difficulty, and an anti-farm fix. (BETA)
- Gameplay extras (BETA): Player QoL, HP Drain, longer Tachy, harder enemies x2-x6, no fall damage, no water/sand death, less Tachy drain, stronger gear x2, Beta/Burst on perfect parry/dodge (no skill tree), wider perfect-timing window, double air dodge, enemy variety.
- Custom TOML patches: drop your own <Table>.toml row/property patches on top. (BETA)
- Auto-detects the game and, with your approval, installs mod + helper (and can uninstall exactly what it installed). History of builds you can reuse as templates or re-export.
- Ships embedded Python (nothing to install); reads Oodle from your own game to pack. Needs Stellar Blade installed for this tab.

READING ZEN/IOSTORE MODS
Most Stellar Blade mods ship as Zen/IoStore containers. Stellar Tool reads them with CUE4Parse - point it at your Stellar Blade folder once (Settings; it auto-detects Steam). Numbers, text, enums, arrays, object fields and whole rows are written back and verified. New rows are reconstructed safely, scalar arrays work even when vanilla starts empty, and row removals are supported with a guard against suspicious mass loss. If a game update makes the bundled mappings stale, Settings -> Mappings can download the matching .usmap for your game version, or load your own. If something fails, the real reason is recovered and written to a diagnostic log in %LOCALAPPDATA%\StellarTool\logs\ - attach the newest one when reporting an issue.

INSTALL
1. Download and extract anywhere. Run StellarTool.exe.
2. Drag your mods in, review, and Merge everything.
3. Copy the generated files to StellarBlade\SB\Content\Paks\~mods, or install the generated zip with your mod manager.
4. Disable/remove the source mods you merged (the tool offers a one-click button for this).

REQUIREMENTS AND CONFLICTS
- Windows 10/11. No game file is ever touched.
- The merged pak conflicts, by definition, with the mods you merged into it - disable them.
